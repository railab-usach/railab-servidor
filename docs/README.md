# Documentación del servidor del RAI Lab

Este `docs/` es un vault de Obsidian y también se lee en GitHub: los enlaces son markdown relativos. Para abrirlo en Obsidian, usa «Abrir carpeta como vault» sobre la raíz del repo.

## Secciones
- [Decisiones (ADR)](decisiones/README.md): qué se decidió, por qué y qué falta validar. Léelo antes de cambiar algo del servidor.
- [Hardware](hardware/hp-node-01.md): la ficha de `hp-node-01` y de los otros Z420.
- [Guías](guias/README.md): tareas paso a paso para quien llega al lab.
- [Bitácora](bitacora/README.md): qué se hizo cada jornada.

## Para quien llega
1. Lee este índice y el [índice de ADR](decisiones/README.md) (10 minutos).
2. Pide acceso siguiendo la guía de llaves SSH ([guías](guias/README.md)).
3. Elige un reto o una guía por escribir y avísalo en el grupo.

# Guías del servidor

Guías cortas, de una tarea cada una, escritas para alguien que llega al lab por primera vez. Cada guía dice qué vas a aprender, qué necesitas y cómo saber que funcionó.

| Guía | Qué aprendes | Estado |
|---|---|---|
| Conectarte a la red del lab | Qué es una VPN y qué es Tailscale | por escribir |
| Crear tu llave SSH y pedir acceso | Llaves públicas y privadas, `ssh`, `~/.ssh/config` | por escribir |
| Git y GitHub en 30 minutos | `clone`, `commit`, `push`, ramas, *pull requests* | por escribir |
| Instalar el servidor desde cero | `apt`, usuarios, systemd, `uv` | por escribir |
| Agregar un servicio nuevo | Archivos `.service`, registros con `journalctl` | por escribir |
| [Zulip del lab](zulip.md) | Canales, temas y puesta en marcha del chat del lab | lista |
| Proponer una decisión (ADR) | Escribir opciones y criterios antes de programar | ver la [plantilla](../decisiones/0000-plantilla.md) |

Cualquiera puede tomar una guía: escribirla es la mejor forma de aprender el tema. Los retos están en el repo [inmoov-cabeza](https://github.com/railab-usach/inmoov-cabeza).
